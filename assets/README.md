# Banner logo

The banner at the top of the window shows a logo when this folder contains one of:

```
logo.png   logo.jpg   logo.jpeg   logo.bmp   logo.gif
```

- Use the official logo file from your organisation's brand assets. A PNG with a transparent
  background looks best; it is scaled to 30 pixels high, so anything from about 60 pixels high is fine.
- Without a logo file the banner shows only the tool name and the credit.
- `logo.*` in this folder is git-ignored on purpose: a company logo is a trademark and does not
  belong in a public repository. Each person who uses the tool adds the file locally.
